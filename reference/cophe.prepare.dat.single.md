# Prepare data for cophe.single

Prepare data for cophe.single

## Usage

``` r
cophe.prepare.dat.single(dataset, querysnpid, MAF = NULL)
```

## Arguments

- dataset:

  a list with specifically named elements defining the query trait
  dataset to be analysed.

- querysnpid:

  Id of the query variant, (id in dataset\$snp)

## Value

named list containing the per snp BFs (df) and position of the query
variant (querypos)
