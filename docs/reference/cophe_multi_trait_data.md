# Simulated multi-trait data

Simulated multi-trait data

## Usage

``` r
data(cophe_multi_trait_data)
```

## Format

list of coloc structred datasets for 24 traits
(cophe_multi_trait_data\$summ_stat), LD matrix
(cophe_multi_trait_data\$LD) and the id of the query snp
(cophe_multi_trait_data\$querysnpid). \#' The trait dataset are
simulated summary statistics (1000 SNPs) for 10 Hn, 10 Ha and 10 Hc.
